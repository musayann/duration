# Duration

A responsive, dependency-free website for converting `hh:mm:ss` into decimal hours, rounded to two decimal places.

Open `index.html` directly in a modern browser. No install or build step is required. To serve locally, run `python3 -m http.server 8000` and visit `http://localhost:8000`.

Enter a duration or select an example to get an instant result. Hours may exceed 24; minutes and seconds must each be two digits from `00` to `59`. Calculations stay in your browser.

Deploy by uploading `index.html`, `styles.css`, and `app.js` to any static web host.
